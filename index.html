About Me

I am a versatile backend software engineer with deep expertise across both Java (Spring Boot) and Node.js (JavaScript/TypeScript). My current primary tech stack centers on architecting enterprise-grade microservices with Java and Spring Boot, backed by extensive experience with Node.js where I have more than double that tenure designing scalable, event-driven backend systems.

Working deeply across both the JVM and JavaScript runtimes enables me to leverage the right architectural patterns for each challenge—combining Java's robust enterprise multithreading and strong typing with Node.js's asynchronous I/O and lightweight microservices. Across both ecosystems, I specialize in scalable API design, database layer optimization (Hibernate/JPA, raw SQL, NoSQL), and concurrency tuning.

I document architectural patterns and engineering lessons on my blog, Still Debugging. Beyond building production backends, I actively solve algorithmic challenges on LeetCode and explore distributed systems design.
